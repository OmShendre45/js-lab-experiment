    <script>

        let totalChecks = 0;
        let palindromeCount = 0;
        let notPalindromeCount = 0;

        function checkPalindrome() {

            let input = document.getElementById("userInput").value;

            let cleanStr = input
                .toLowerCase()
                .replace(/[^a-z0-9]/g, '');

            let reversedStr = cleanStr
                .split('')
                .reverse()
                .join('');

            let result = document.getElementById("result");
            let reverse = document.getElementById("reverse");

            if (cleanStr === "") {

                result.innerHTML = "Please enter a valid value!";
                result.className = "failure";
                reverse.innerHTML = "";
                return;

            }

            totalChecks++;

            if (cleanStr === reversedStr) {

                palindromeCount++;

                result.innerHTML = "✓ It is a Palindrome!";
                result.className = "success";

            } else {

                notPalindromeCount++;

                result.innerHTML = "✗ It is Not a Palindrome!";
                result.className = "failure";

            }

            reverse.innerHTML =
                "Reversed Text: " + reversedStr;

            updateStats();

        }

        function updateStats() {

            document.getElementById("total").innerHTML =
                totalChecks;

            document.getElementById("yes").innerHTML =
                palindromeCount;

            document.getElementById("no").innerHTML =
                notPalindromeCount;

        }

        function clearData() {

            document.getElementById("userInput").value = "";
            document.getElementById("result").innerHTML = "";
            document.getElementById("reverse").innerHTML = "";

            document.getElementById("userInput").focus();

        }

        function handleEnter(event) {

            if (event.key === "Enter") {
                checkPalindrome();
            }

        }

2. Theory
A palindrome is a word, number, or sentence that reads the same forward and backward.

The Palindrome Checker is a web-based application developed using HTML, CSS, and JavaScript. It accepts input from the user and checks whether the entered word or sentence is a palindrome.

Working of the application:
1. HTML is used to create the input field, buttons, result section, and statistics section.
2. CSS is used to provide an attractive user interface with colours, gradients, buttons, and styling.
3. JavaScript takes the input entered by the user.
4. The toLowerCase() function converts the input into lowercase.
5. The replace() function removes spaces and special characters.
6. The split() function converts the string into an array.
7. The reverse() function reverses the array.
8. The join() function converts the reversed array back into a string.
9. The original cleaned string is compared with the reversed string.
10. If both strings are equal, the input is a palindrome; otherwise, it is not a palindrome.
Additional features:
- Displays the reversed text.
- Provides success and failure messages.
- Maintains total checks, palindrome count, and non-palindrome count.
- Supports checking through the Enter key.
- Provides a Clear button to reset the input and result.
